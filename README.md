# AI-Based Multi-Disease Spread Prediction System

An ensemble forecasting platform that predicts the spread of five infectious diseases across
Indian states, combining a **statistical model (ARIMA)**, a **neural network (MLP)**, and an
**epidemiological compartmental model (SEIR)** behind a Flask web app with live dashboards and an
automated risk/alert engine.

🔗 **Live demo:** https://disease-spread.onrender.com/

> ⚠️ **Academic / educational prototype — not for clinical or policy use.**
> This is a student team project built to demonstrate time-series and epidemiological forecasting.
> It runs entirely on a **synthetic dataset** (algorithmically generated with realistic
> constraints) and its forecasts must **not** be used for any real medical, public-health, or
> government decision-making.

---

## Features

- **Manual Prediction Mode** — pick a disease, region, and horizon (7/14/30 days) to view an
  ensemble forecast, per-model breakdown, SEIR R₀, and a categorical risk assessment.
- **Auto Surveillance Mode** — scans every disease across all regions, ranks them by risk score,
  and generates automated alerts for the highest-burden hotspots.
- **Government Dashboard** — KPIs, 30-day trends, top-risk regions, a live SEIR projection, and an
  **honest model-accuracy backtest**.
- **About Page** — project overview, architecture, and team.

## How it works

### Models
| Model | Type | Role |
|-------|------|------|
| **ARIMA** `(2,1,2)` | Statistical time-series | Captures linear trend/seasonality (statsmodels). Falls back to linear-trend extrapolation. |
| **Neural Net (MLP)** | Feed-forward neural network | Learns non-linear patterns from a 7-day sliding window (scikit-learn `MLPRegressor`). Falls back to a weighted moving average. |
| **SEIR** | Compartmental epidemiology | Simulates Susceptible→Exposed→Infectious→Recovered dynamics with a dynamic β modulated by temperature, humidity, and rainfall; reports R₀. |

These are combined by [`prediction_engine.py`](prediction_engine.py) into a weighted ensemble
(`0.5·NeuralNet + 0.3·ARIMA + 0.2·SEIR`, with weights rebalanced if the neural net is unavailable),
then passed to a rule-based **risk classifier** ([`risk_analyzer.py`](risk_analyzer.py)) that emits
Low/Medium/High tiers and human-readable alerts.

> **Why an MLP instead of a TensorFlow LSTM?** The neural-net slot uses a lightweight scikit-learn
> `MLPRegressor` rather than a TF/Keras LSTM so the whole app fits inside a **512 MB free-tier
> instance** (importing TensorFlow alone would exhaust that memory). The interface is identical —
> swap in a TF LSTM if you deploy to a larger host.

### Data
A **synthetic** daily dataset (`dataset.csv`) covering 5 diseases × 28 Indian states with columns
`Date, Region, Disease, Cases, Temperature, Humidity, Rainfall`. Generated by
[`data_generator.py`](data_generator.py) using patterns informed by public epidemiological reports,
then validated and smoothed at load time. The committed file is trimmed to the most recent ~2 years
to keep memory low; [`data_loader.py`](data_loader.py) also synthesizes recent days up to the
current date.

### Model evaluation
Accuracy on the dashboard comes from an **honest holdout backtest**: the most recent 14 days are
hidden, forecast from the earlier history only, and compared against the held-out actuals (true
out-of-sample RMSE + accuracy). **No accuracy figures are hardcoded.**

## Project structure
```
app.py                 Flask routes, chart rendering
prediction_engine.py   Ensemble predict() + honest backtest()
data_loader.py         Load / validate / smooth the dataset
risk_analyzer.py       Risk classification, alerts, auto-surveillance
data_generator.py      Synthetic dataset generator
run_model_cli.py       Quick CLI demo of the ensemble
models/
  arima_model.py       ARIMA forecaster (+ linear fallback)
  lstm_model.py        Neural-net (MLP) forecaster (+ moving-average fallback)
  seir_model.py        SEIR compartmental simulation
templates/             index, manual, auto, dashboard, about
static/css/            styling
dataset.csv            synthetic data (committed, ~2 years)
```

## Setup

1. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the application**
   ```bash
   python app.py
   ```

3. **Access** — open `http://127.0.0.1:5000/`

To regenerate the full historical synthetic dataset locally:
```bash
python data_generator.py
```

## Deployment (Render)
The repo includes [`render.yaml`](render.yaml) and [`build.sh`](build.sh) for one-click deployment
as a Python web service. The build installs dependencies; the trimmed dataset ships with the repo.
Served with Gunicorn (`--workers 1 --threads 2 --timeout 120`) to stay within the free-tier memory
and cover slow first-request model training.

## Disclaimer
This project uses active ML models (ARIMA, a Neural Network/MLP, and SEIR) for spread prediction.
The underlying dataset is **synthetic** — algorithmically generated with realistic constraints,
geographical correlations, and meteorological limits for demonstration purposes only. It does not
represent real outbreaks, and its forecasts must not be used for any actual medical, public-health,
or policy decisions.
